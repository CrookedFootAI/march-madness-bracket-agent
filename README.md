# March Madness Bracket Agent

An AI-powered March Madness bracket prediction site built as a vibe-coding experiment.

🔗 **Live site:** https://march-madness-bracket-agent.netlify.app/

## Overview

March Madness Bracket Agent is a lightweight sports prediction project designed to generate NCAA tournament bracket picks using multiple tournament signals instead of pure gut feel.

The goal of this project was to experiment with AI-assisted product creation, rapid prototyping, and sports-focused UX design while building something fun, shareable, and timely for March Madness.

## Features

- AI-powered bracket pick generation
- Refreshable bracket recommendations
- Tournament-focused prediction logic
- Consumer-style sports UI built for quick interaction
- Built and iterated as a vibe-coding project

## Signals used

The bracket logic is designed to consider multiple tournament-style inputs, including:

- Injury reports
- Travel burden
- Upset history
- NIL spending
- Player focus / momentum indicators
- Betting-related context

> Note: This project is intended as a fun experimental bracket tool and not as a guaranteed prediction model.
